# مساعد اشتراطات السلامة — الكود السعودي (SBC 201 / SBC 801)
## Saudi Building & Fire Code Interactive Compliance Tool (Open Source — GitHub Pages Ready)

أداة هندسية مفتوحة المصدر تعمل **100% بدون إنترنت** (Static HTML/CSS/JS — بدون الحاجة لأي خادم خلفي أو بناء معقد)، مبنية لتجميع وتنظيم **41 ملفاً مرجعياً** في الوقاية والحماية من الحريق ضمن **10 مواضيع هندسية مترابطة**.

---

## ✅ ما يتضمنه الإصدار الحالي (النموذج الأول — الموضوع 01 مكتمل)
يدمج **الموضوع 01** خمسة ملفات PDF مرجعية في واجهة تفاعلية واحدة:
1. `Means of Egress Components.pdf` — مكونات مسار الهروب الثلاثة (`SBC 1001–1032`)
2. `OCCUPANT LOAD CALCULATION.pdf` — حساب حمل الإشغال، المقاعد الثابتة، الميزانين، والتقاء الأدوار (`SBC 1004 & 1005.6`)
3. `Means of Egress Width.pdf` — حساب عروض السلالم والأبواب والممرات وقاعدة فقد مخرج 50% (`SBC 1005`)
4. `Number Of Exits.pdf` — عدد المخارج للفراغات والأدوار، الاستخدامات الخاصة الستة، وشروط المخرج الواحد (`SBC 1006`)
5. `EXIT AND EXIT ACCESS DOORWAY CONFIGURATION.pdf` — مسافة التباعد ($D/2$ أو $D/3$) وحكم السلالم المتشابكة (`SBC 1007`)

### المزايا المدمجة:
- حاسبة فورية تفاعلية تتكيف تلقائياً مع 16 فئة إشغال.
- تفعيل حي لاستثناءات الكود (Checkboxes) مع تحديث لحظي للمطابقة.
- أمثلة جاهزة (مستشفى I-2 / قاعة مؤتمرات A-3 / مكتب إداري B).
- تصدير مباشر لتقرير CSV (متوافق مع Microsoft Excel باللغة العربية) + طباعة PDF نظيفة.
- خارطة مرجعية كاملة لجميع الـ 41 ملفاً مقسمة إلى 10 مواضيع.

## 🚀 خطوات النشر المجاني على GitHub Pages (في 3 دقائق)

1. أنشئ مستودعاً جديداً (Repository) على حسابك في **GitHub** (مثلاً باسم `sbc-safety-assistant`) واجعله **Public**.
2. فك ضغط الملف `SBC_Safety_Assistant_GitHub_Topic01.zip` وارفع جميع الملفات الموجودة بداخله (`index.html`، مجلد `assets/`، `README.md`، `.nojekyll`) إلى جذر المستودع (Root).
3. من داخل المستودع اذهب إلى:
   **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
4. خلال دقيقة واحدة سيصبح موقعك متاحاً مجاناً عبر الرابط:
   `https://<your-username>.github.io/sbc-safety-assistant/`
   *(ويمكنك ربطه بدومينك الخاص مباشرة عبر إعداد Custom Domain وسجل CNAME في GitHub Pages).*
